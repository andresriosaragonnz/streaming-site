# Videographer Media Proxy Worker Setup

To secure media files hosted in your Cloudflare R2 bucket and prevent unauthorized hotlinking or scraping, you need to configure the `PLATFORM_SECRET` environment variable on your storage proxy Worker.

This shared secret allows your Worker to verify cryptographic HMAC-SHA256 signatures generated by `iknowthatband.org`.

---

## Method 1: Using Wrangler CLI (Terminal)

If you have the Worker project on your machine, you can upload the encrypted secret using Wrangler:

1. Open your terminal in the root directory of the proxy Worker project.
2. Run the `secret put` command:

   ```bash
   npx wrangler secret put PLATFORM_SECRET
   ```

Method 2: Using Cloudflare Dashboard (Browser UI)If you prefer configuring secrets through the Cloudflare web interface:Log in to the Cloudflare Dashboard.In the left navigation menu, go to Compute (Workers & Pages) $\rightarrow$ Workers & Pages.Select your media proxy Worker (e.g., videographer-media-proxy).Click the Settings tab near the top of the screen.In the left sidebar of the settings page, select Variables.Under the Environment Variables section, click Add variable.Enter the following details:Variable name: PLATFORM_SECRETValue: Paste the shared secret key.Click Encrypt to lock the secret value.Click Save and Deploy.
